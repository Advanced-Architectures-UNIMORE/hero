Build di petalinux
cp Image system.dtb /opt/tftpboot/gbellocchi/
tar -xf rootfs.tar.gz -C /opt/rootfs/gbellocchi/

1. Reset della board
xsdb 
source ./reset-31212.tcl (deve esserci anche il pmufw.elf nella stessa dir)

Se ci sono problemi con xsdb, prova a vedere ps e alla peggio fare kill -9 <PROCESS>

2A. Boot di petalinux con bitstream (da Ritchie)
Vai dentro /petalinux/zcu102 ed esegui:
petalinux-boot --jtag --u-boot --fpga --bitstream <POSIZIONE-BITSREAM> -v --hw_server-url 127.0.0.1:31212

2B. Boot di petalinux con bitstream (da Kernighan)
Vai dentro /petalinux/zcu102 ed esegui:
petalinux-boot --jtag --u-boot --fpga --bitstream <POSIZIONE-BITSREAM> -v --hw_server-url 155.185.4.26:31212

If you get an error that says you don't have PETALINUX set, then just source this script that is located in
the Petalinux installation folder: 
source /var/pkg/ritchie/Xilinx/petalinux/2017.2/settings.sh 
(refer to https://forums.xilinx.com/t5/Embedded-Linux/Error-when-trying-to-use-petalinux-create/td-p/862151)

3. Accedere alla Zynq
Vai su Ritchie via SSH ed esegui:
minicom usb<PORTA-USB>
La porta può cambiare di volta in volta.

4. Lancia la board
Copia e lancia uno alla volta i comandi “my-u-boot-cmd.txt” su minicom.

setenv tftpblocksize 512

(hero)
setenv bootargs console=ttyPS0,115200n8 earlycon clk_ignore_unused cpuidle.off=1 ip=155.185.4.7:155.185.4.26:155.185.5.254:255.255.254.0::eth0:off root=/dev/nfs rootfstype=nfs nfsroot=155.185.4.26:/opt/hero/rootfs,tcp,nolock,nfsvers=3 rw
(xilinx_deployment)
setenv bootargs console=ttyPS0,115200n8 earlycon clk_ignore_unused cpuidle.off=1 ip=155.185.4.7:155.185.4.26:155.185.5.254:255.255.254.0::eth0:off root=/dev/nfs rootfstype=nfs nfsroot=155.185.4.26:/opt/rootfs/gbellocchi,tcp,nolock,nfsvers=3 rw uio_pdrv_genirq.of_id=generic-uio cma=256M

Carica il kernel di Linux all’indirizzo 0x200000:
tftpb 0x200000 gbellocchi/Image

Carica il device tree all’indirizzo 0x7000000:
tftpb 0x7000000 gbellocchi/system.dtb

Fai il boot col kernel di Linux all’indirizzo 0x200000 con gli argomenti successivi
booti 0x200000 - 0x7000000 ${bootargs}

Togli e rimetti i driver di PULP:
rmmod -f pulp
insmod /mnt/lib/modules/4.9.0/extra/pulp.ko

oppure da openmp-examples/common:
make -f default.mk init-target-host
